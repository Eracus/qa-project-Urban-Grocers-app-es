# Proyecto Urban Grocers



\# Mi Proyecto del Sprint 8



\## 1. Descripción del proyecto



Realizar un conjunto de pruebas automatizadas para la API de usuarios, kits y almacenes, basándose en una lista de comprobación (\*checklist\*). Posteriormente, cargar el código en GitHub y enviar el repositorio para su revisión.



\## 2. Fuente de documentación utilizada



\- Documentación de la API generada con \*\*apiDoc\*\*, proporcionada como parte de las instrucciones del proyecto.



\## 3. Tecnologías y técnicas utilizadas



\### Tecnologías



\- \*\*Lenguaje de programación:\*\* Python.

\- \*\*Librería:\*\* Requests.

\- \*\*Repositorio y control de versiones:\*\* GitHub.



\### Técnicas y tipos de pruebas realizadas



\- Validación del número permitido de caracteres (1).

\- Validación del número permitido de caracteres (511).

\- Validación de valores con menos caracteres de los permitidos (0).

\- Validación de valores con más caracteres de los permitidos (512).

\- Validación de caracteres especiales.

\- Validación de espacios.

\- Validación de números.

\- Pruebas de parámetros que no se envían en la solicitud.

\- Pruebas con tipos de parámetros incorrectos (números).
